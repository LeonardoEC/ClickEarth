# ClickEarth

ClickEarth es un juego 2D simple en el que cada clic suma puntos de manera infinita, mientras el mundo gira en el espacio. Es un proyecto desarrollado como parte de un desafío personal de crear un juego simple por semana para mejorar habilidades en **Unity**.

## 🎮 Características

- Juego casual con mecánica de clic infinito.
- Animación de rotación del mundo con cada clic.
- Proyecto **2D** desarrollado en Unity.
- Uso de imágenes generadas con la IA **Leonardo**.

## 📜 Objetivo del proyecto

Este y otros proyectos con el _release de estudiando_ son totalmente **sin fines de lucro** y han sido creados únicamente con el propósito de:
- Aprender a utilizar **Unity**.
- Mejorar habilidades de desarrollo de videojuegos.
- Crear un portafolio demostrativo del progreso en el aprendizaje.

## 🚀 Cómo jugar

1. Descarga o clona el repositorio.
2. Abre el proyecto en Unity.
3. Ejecuta la escena principal y comienza a hacer clic para acumular puntos y ver el mundo girar.
